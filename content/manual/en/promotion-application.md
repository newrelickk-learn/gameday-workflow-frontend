# How to submit a promotion application

This is the procedure for a manager to apply for a promotion for one of their members. Only a manager can submit a promotion application.

## Steps

1. Open "Applications" from the dashboard and choose "New application".
2. Select "Promotion" as the application type.
3. Enter the title and the description.
4. Review the details and submit.

## Fields

| Field | What to enter |
| --- | --- |
| Title | A short name that identifies the promotion (for example: Promotion application for Taro Yamada) |
| Description | Follow the template below |

## Format of the description

Start the description with the following template.

```
Target: (email address of the person)
Details: Promotion: (current grade) -> (new grade)
```

**Example**:

```
Target: yamada.taro@learn.nrkk.technology
Details: Promotion: L3 -> L4

Recognising their project management results and technical leadership in the current role, I am applying for this promotion.
```

The grade transition must be written in the `L3 -> L4` form. This is the part the validation rule checks, so keep the arrow notation even when you write the rest in your own words.

## Approval

A promotion application follows the company approval flow. Once it is approved, the grade change is confirmed.

## Troubleshooting

If the application fails with an error and you cannot tell why, ask the AI (Autopilot) in the New Relic UI.

A knowledge base called "Workflow Promotion Trouble Shoot" is available for investigating this application. Type `/` in the New Relic AI chat to list the knowledge bases, select "Workflow Promotion Trouble Shoot", and then describe what is happening.
