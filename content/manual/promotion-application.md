# プロモーション申請の書き方

メンバーの昇進（プロモーション）を上長が申請するための手続きです。プロモーション申請は、上長（マネージャー）のみが行えます。

## 申請の流れ

1. ダッシュボードの「申請一覧」から「新規申請」を選択します。
2. 申請タイプで「プロモーション申請」を選びます。
3. タイトル・説明を入力します。
4. 内容を確認し、申請を確定します。

## 入力項目

| 項目 | 内容 |
| --- | --- |
| タイトル | 対象者の昇進が分かる短い名称（例: 山田太郎氏 プロモーション申請） |
| 説明 | 昇進理由・実績・等級の変化などの詳細 |

## description（説明欄）の書式

説明欄には、対象者の**現在の等級 → 昇進後の等級**を、社内規定の書式に従って記載してください。

現在の等級と昇進後の等級は、`L3->L4` のように、半角の `->`（半角ハイフン + 半角の大なり記号）でつなげて記載してください。

**記載例**:

```
L3->L4

現職でのプロジェクトマネジメント実績、技術リード経験を評価し、
L3からL4への昇進を申請します。
```

等級の記載は説明欄の先頭にまとめておくと、承認者が確認しやすくなります。

## 承認について

プロモーション申請は、社内の承認フローに従って処理されます。承認が完了すると、対象者の等級変更が確定します。
